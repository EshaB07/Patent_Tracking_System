# PatentVault – Patent Ownership Management System

PatentVault is a database-driven web application developed as a college DBMS project. It provides a centralized platform to manage patent information, ownership records, contracts, and collaborators.

## Live Demo
[PatentVault – Frontend Demo](https://patentvault.vercel.app/)  
*Note: This is a frontend-only deployment hosted on Vercel. The Java/MySQL backend is not integrated, and all data operations use predefined sample data that resets on page refresh.*
## Project Overview

PatentVault aims to simplify patent ownership management by allowing users to register patents, maintain ownership records, manage contracts, and track patent-related information through a user-friendly interface.

## Features

- **Patent Management:** Register and manage patent details.
- **User Management:** Maintain registered users and creators.
- **Ownership & Contracts:** Manage patent ownership records and ownership agreements.
- **Collaborator Management:** Assign collaborators to patents.
- **Patent Status Tracking:** Track patents with statuses such as Granted, Pending, and Terminated.
- **Reports:** Generate reports related to patent status, creators, contract amounts, and active contracts.
- **Duration Calculator:** Calculate the duration of ownership contracts.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Java
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **Build Management:** Apache Maven

## Database

PatentVault uses MySQL to store and manage application data.

The database supports information related to:
- Patents
- Registered users and creators
- Patent ownership
- Ownership contracts
- Collaborator assignments

## Project Purpose

This project was developed as part of an academic Database Management Systems (DBMS) project to demonstrate practical implementation of database connectivity, relational data management, CRUD operations, and report generation.
